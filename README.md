# Hack-Nation_QX

AutoComply – KI-gestützte Compliance-Prüfung für Gutachten (FastAPI + Next.js).

## Setup

### Backend (API)

```bash
cd api
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

API: http://localhost:8000 · Frontend: http://localhost:3000
